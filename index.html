How to Use This Tool

1. Export Modpack

First, export your existing modpack as a .mrpack file from your launcher (e.g., Prism Launcher, Modrinth App).

2. Upload

Click "Choose File" on this page and select your local .mrpack file to begin.

3. Set Versions

Select the target Minecraft and Fabric Loader versions you want to update to.

4. Check Updates

The tool will analyze your mods against the Modrinth database for compatibility.

5. Customize

Review the list and decide the action for each mod (Update, Keep, Disable, Remove).

6. Generate

Click "Download" to get your freshly updated and configured .mrpack file.

7. Install

Import the new .mrpack file into your launcher to create a new, updated instance.

8. Enjoy

Start your updated Minecraft instance and enjoy!
